**ImanAdmin** پنل مدیریت فروشنده نرم‌افزار **ImanAccount** است که به فروشنده اجازه می‌ده:

- 📊 مدیریت داشبورد فروش
- ➕ ایجاد مشتری + تولید لایسنس
- 👥 مدیریت مشتریان
- 📄 فاکتورهای خدمات حسابداری
- 🎁 تولید Trial Certificate
- 🔐 امضای پلاگین
